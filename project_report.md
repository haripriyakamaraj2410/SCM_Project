# Project Report  
## Software Configuration Management for an E-Commerce Website
### 1. Introduction
This project demonstrates the implementation of Software Configuration Management (SCM) for an E-Commerce Website. SCM helps in tracking, managing, and controlling changes in the project.
The system uses GitHub for version control and Jenkins for continuous integration. Docker is also used for containerized deployment.
### 2. Problem Statement
Managing multiple files in a web project becomes difficult without proper tools. Issues include:
- No version tracking
- File conflicts
- Difficult deployment
This project solves these problems using SCM practices.
### 3. Objectives
- To implement version control using GitHub
- To automate build process using Jenkins
- To manage project files effectively
- To enable easy deployment using Docker
### 4. Project Description
The project is a static E-Commerce Website built using HTML and CSS.
#### Features:
- User login and account management
- Product categories (Fashion, Grocery, Mobiles)
- Buy and sell functionality
- Order management
### 5. Tools Used
- GitHub (Version Control)
- Git (Tracking changes)
- Jenkins (Continuous Integration)
- Docker (Containerization)
### 6. SCM Activities
#### Version Control
All files are managed using GitHub with proper commits.
#### Change Control
Changes are updated, committed, and tracked.
#### Build Management
Jenkins automatically builds the project.
### 7. Results
- Successful integration of GitHub and Jenkins
- Automated build process
- Proper version tracking
- Docker-based deployment
### 8. Conclusion
The project successfully demonstrates SCM practices. It improves project management, reduces errors, and ensures smooth development and deployment.
